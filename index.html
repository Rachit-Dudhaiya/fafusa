STOP! Game Rules

1. The Alphabet Roll: One player starts the roll (A, B, C...). The designated opponent hits STOP to select the letter.

2. Filling Categories: All players must write words starting with that letter for every category (Name, Place, Animal, Thing, Movies, etc.).

3. Calling STOP: If any player completes all columns, they can hit the big STOP! button, ending the round immediately for everyone!

4. Scoring System:

  • Unique answer (no other player wrote the same thing): +1 point.
  • Duplicate answer (two or more players wrote the identical word): 0 points.
  • Empty or invalid: 0 points.

Host can override and validate or disqualify contested answers on the review screen.
